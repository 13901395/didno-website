# کانون تبلیغات دیدنو — نسخه حرفه‌ای

## امکانات
- طراحی فروشگاهی RTL و واکنش‌گرا با تم سبز کله‌غازی + فیروزه‌ای
- دسته‌بندی خدمات چاپ، صحافی، تبلیغات، تابلو، اداری، طراحی، هدیه تبلیغاتی و دیجیتال
- سبد سفارش و ثبت سفارش آنلاین
- قیمت نمونه برای خدمات قابل قیمت‌گذاری
- گزینه «تماس بگیرید» برای خدمات پروژه‌ای
- ثبت‌نام و ورود کاربران
- پنل مدیریت برای افزودن، ویرایش، حذف و فعال/غیرفعال کردن خدمات و تغییر قیمت
- مدیریت وضعیت سفارش‌ها
- API سلامت برای Render

## اجرای محلی
```bash
npm install
npm start
```
سپس:
http://localhost:3000

## متغیرهای محیطی پیشنهادی در Render
ADMIN_EMAIL
ADMIN_PASSWORD
AUTH_SECRET
NODE_ENV=production

اگر این متغیرها تنظیم نشوند، برای تست از مدیر پیش‌فرض پروژه استفاده می‌شود؛ برای سایت واقعی حتماً رمز مدیر را در Environment Variables تغییر دهید.

## نکته مهم دیتابیس
نسخه فعلی برای شروع سریع از data.json استفاده می‌کند. برای استفاده تجاری جدی و جلوگیری از ازبین‌رفتن سفارش‌ها در ری‌استارت/دیپلوی Render، مرحله بعدی بهتر است به PostgreSQL/Supabase متصل شود.

## هدر جدید
لوگوی اصلی دیدنو و تصویر هدر تبلیغاتی در `public/didno-logo.png` و `public/didno-hero.png` قرار گرفته‌اند و حباب‌های پیام به‌صورت CSS انیمیشنی حرکت می‌کنند.
