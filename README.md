# سایت کانون تبلیغات دیدنو

## اجرا
1. Node.js نسخه 18 یا بالاتر نصب باشد.
2. داخل همین پوشه اجرا کنید:
   npm install
   npm start
3. مرورگر: http://localhost:3000

## حساب مدیر اولیه
ایمیل: admin@didno.ir
رمز: Admin12345!

حتماً بعد از راه‌اندازی، رمز مدیر را در نسخه واقعی تغییر دهید و SESSION_SECRET را در متغیر محیطی تنظیم کنید.

## امکانات
- صفحه اصلی مدرن و ریسپانسیو
- خدمات قابل مدیریت
- ثبت‌نام و ورود
- ثبت سفارش آنلاین
- پایگاه داده SQLite
- پنل مدیریت
- مشاهده آمار
- مدیریت وضعیت سفارش‌ها
- افزودن خدمت از پنل

## برای انتشار واقعی
این پروژه یک نسخه پایه فول‌استک است. برای محیط واقعی بهتر است HTTPS، ایمیل تأیید، بازیابی رمز، محدودیت درخواست، بکاپ دیتابیس و درگاه پرداخت اضافه شود.
